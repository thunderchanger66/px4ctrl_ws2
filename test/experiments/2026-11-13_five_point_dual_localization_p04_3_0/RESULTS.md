# 五点双定位标准性能重测

## 测试条件与判据

本批次独立重新测试五个目标点，不引用此前批次结果。P04 按最新要求设为 `(3,0,0.5)`。每个点均单独启动 PX4/Gazebo、FAST-LIO/PGO 和 bringup，执行起飞、稳定等待、`--auto-yaw` 目标、数据采集和降落；五轮结束后关闭整套仿真。五个 `result.json` 均记录 `trial_valid=true`、`result=arrived`、`landing_confirmed=true`。

使用当时活动的 C1 控制器参数；EGO 动态上限为速度 `1.0 m/s`、加速度 `1.0 m/s²`、jerk `3.0 m/s³`，障碍膨胀 `0.45 m`，优化器清距 `0.65 m`。目标坐标为 lidar/map 规划坐标。

- **FAST-LIO/lidar 跟踪误差**：EGO PositionCommand 与 FAST-LIO lidar-frame odometry 的 3D 位置差，统计 RMSE、P95、最大值。
- **FAST-LIO 终点误差**：稳定到达判定时，FAST-LIO 最终位置到 lidar-frame 目标的距离。
- **PX4 本地 NED 跟踪误差**：坐标适配器输出的期望 NED 位置与 PX4 `VehicleLocalPosition` 位置差，统计 RMSE、P95、最大值。
- **PX4 NED 终点误差**：PX4 最终本地 NED 位置到适配器最后一条 NED 目标参考的距离。该目标参考经过坐标变换，与 FAST-LIO 直接对 lidar 目标的误差不是同一个定义。
- **到达**：FAST-LIO 到目标距离 `<=0.20 m` 且速度 `<=0.20 m/s`，连续保持 `1 s`。
- **地图余量门槛**：最近发布的 EGO 膨胀占据体素中心距离 `>=0.50 m`。这是地图余量代理值，不是 Gazebo 碰撞传感器或机体扫掠碰撞检测。

## 结论

- 五个目标均完成轨迹跟踪，到达判据通过，且每轮都确认降落并解锁；本批次没有 bridge 启动失败记录，也没有 px4ctrl failsafe 采样。
- P04 `(3,0,0.5)` 正常生成轨迹并到达，FAST-LIO 终点误差 `0.083 m`，PX4 NED 终点误差 `0.060 m`，用时 `9.986 s`，地图余量代理值 `0.895 m`。这次结果取代旧报告中的 P04 超时/未落地结论。
- 按 `0.50 m` 地图余量门槛，P04 和 P05 通过；P01、P02、P03 未通过。未通过代表该地图余量指标不满足要求，不等于本次发生碰撞；测试没有使用独立机体扫掠碰撞传感器作为判定。
- P01/P02 的速度峰值和参考加速度峰值明显高于 EGO 配置的 `1.0 m/s` 与 `1.0 m/s²`。因此虽然到达，不能据此宣称运动约束满足。应结合原始采样检查轨迹切换和参考变化；该批次记录了 P01 `15` 次 reference blend、`13` 次 acceleration projection，P02 分别为 `6` 和 `9` 次。
- 两套位置误差基于不同坐标链和参考量，分别报告，不应混成单一“定位精度”。本批次 P04 与 P05 的跟踪误差较低；P01/P02 的全程误差和峰值较大。
