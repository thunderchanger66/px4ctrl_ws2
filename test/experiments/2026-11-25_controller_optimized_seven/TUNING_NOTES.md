# 调参过程与取舍

所有候选都使用相同的 PX4 NED 误差定义、EGO 避障代码、MID-360 悬停推力、起飞流程和逐轮完整重启协议。每组先跑误差更敏感的 P01、P02、P04；只对入选配置运行完整七轮。

| 候选 | 控制器 kp / kv | EGO vel / acc / jerk | P01 RMSE | P02 RMSE / 结果 | P04 RMSE / 结果 | PX4 峰值速度/加速度特点 | 结论 |
|---|---|---|---:|---|---|---|---|
| 原接入基线 | `[1.6,1.6,2.0]` / `[1.4,1.4,1.6]` | `1.0 / 1.0 / 3.0` | 0.153 | 0.170 / 到达 | 0.162 / 到达 | 个别点峰值约 `1.25 m/s`, `3.8 m/s²` | 基线，七轮结果见前一批目录 |
| C2 高增益 | `[1.8,1.8,2.2]` / `[1.6,1.6,1.8]` | `1.0 / 1.0 / 3.0` | 0.234 | 0.097 / 未在超时内稳定到达 | 0.281 / 到达但耗时 40.45 s | P04 峰值约 `1.93 m/s`, `4.71 m/s²`，参考峰值加速度 `8.96 m/s²` | 拒绝：高增益未改善一致性，并显著增加 EGO 重规划和控制峰值 |
| EGO 降速一档 | 原目录基线 `[1.5,1.5,1.8]` / `[1.2,1.2,1.4]` | `0.7 / 0.6 / 2.0` | 0.100 | 0.095 / 到达 | 0.113 / 到达 | PX4 峰值速度约 `0.70–0.78 m/s`，加速度约 `0.61–0.84 m/s²` | 改善；多数点低于 0.1 m，但 P01/P04 略高 |
| EGO 平滑档 | 原目录基线 | `0.6 / 0.5 / 1.7` | 0.085 | 0.084 / 到达 | 0.112 / 到达 | 峰值速度约 `0.58–0.60 m/s`；P04 误差仍未低于 0.1 m | 参考更平滑，保留为下一步候选 |
| 最终配置 | 原目录基线 | `0.5 / 0.4 / 1.4` | **0.086** | **0.073 / 到达** | **0.087 / 到达** | P01/P02/P04 峰速约 `0.43–0.47 m/s`；峰加速度约 `0.42–0.61 m/s²` | 入选；完整七轮 RMSE 全部低于 0.1 m |

下降低 EGO 速度/加速度限值后，轨迹追踪误差和实测速度/加速度都下降，代价是较远目标变慢（P06 约 34.95 s）。因此这次达到低 RMSE 的主要手段是限制 EGO 参考的动态要求，而非增大控制器增益。最终控制增益恢复为原 `controller` 包的默认 `[kp]=[1.5,1.5,1.8]`、`[kv]=[1.2,1.2,1.4]`、`[ki]=[0.10,0.10,0.15]`，避免将高增益引起的震荡或重规划循环当作优化。
